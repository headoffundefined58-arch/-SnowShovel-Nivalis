==========================================================
 Nivalis · 雪相 0.5 —— 雪 · 水 · 冰 相变框架
==========================================================

一句话：雪不再只是铺在地上。你把它扫拢，它就跟着时间
化水、冻冰、再被火烤回水，最后汇成水洼渗进土里。

本插件彻底取代「扫扫地 Sweeping Organizes Stuff」：
扫地不再需要任何外部模组，也不再依赖"装备扫帚"那一套。

----------------------------------------------------------
 玩法
----------------------------------------------------------
* 按 I 键（可在菜单里改键，或改 ini 的 SweepKey）原地开始扫地，
  再按一次立即收手停下（会真正打断扫地动作，不必再靠跳跃打断）。
  背包里必须有扫帚 —— 这是固定规则，不放进菜单开关。

* 站在雪地上扫：动态地形变化插件会把雪面挖开一片干净地，
  松雪被扫拢成一小堆（左上角提示）。

* 扫拢的雪堆会跟着游戏时间变化：
  - 白天累积「暖时」到 3 小时 —— 化成水，四处漫开；
  - 夜里累积「寒时」到 5 小时 —— 冻成一块冰。
  （阈值都能在菜单 / ini / phases.yml 里调。）

* 水会汇成水洼（动态血池框架绘制），慢慢渗进土地消失。

* 冰也怕火：站在火堆 / 火盆 / 锻炉旁，冰会被烤回水，
  雪堆则直接化成水。火源识别与动态地形插件用同一份关键词。

----------------------------------------------------------
 依赖关系
----------------------------------------------------------
硬需求：
* 动态地形变化 NMN_DeformableTerrain —— 提供动态雪面，
  扫雪才有雪可扫（本插件不会改它的任何文件）。
* 时间炼成 Alchemy of Time —— 框架声明的时间来源：相变时钟
  就走它那套游戏时间，相变时长也用它 preset 的 yml 写法。
  它不在时相变会停用（想脱离可在 ini 设 PhaseRequireAOT=false）。

软需求（缺了自动降级，不报错）：
* 动态血池框架 —— 提供水洼。没装的话雪照样化，只是没有水。
  水洼样式在 SKSE\DynamicBloodpoolFramework\NivalisWater.json。
* SKSE 菜单框架 —— 提供游戏内设置菜单（中英切换）。

可选 / 可以不要了：
* 扫扫地 Sweeping Organizes Stuff —— 已可停用。本插件自带
  扫地交互与动画，留着它也不会冲突（它触发扫地时本插件会
  顺势跟上）。

----------------------------------------------------------
 游戏内菜单（SKSE 菜单框架）
----------------------------------------------------------
打开 SKSE 菜单框架（默认 Home 键）-> Nivalis -> 雪相。
只保留核心项：状态、扫地、相变、水洼、动态雪面。
扫地一项里可以直接点「改键」——按下想绑的键即可（Esc 取消），
旁边还能「清除绑定」或者一键开始/停止扫地。
右上角可切「中文 / English」，菜单里改的值自动写回
Nivalis.ini，手改 ini / phases.yml 也会即时生效。

----------------------------------------------------------
 配置
----------------------------------------------------------
* SKSE\Plugins\Nivalis.ini —— 全部参数，改完保存即生效。
* SKSE\Plugins\Nivalis\phases.yml —— 相变时长（AOT 风格 yml），
  数值会覆盖 ini 里的同名项；想单点调时长改这里最直观。

常用：
  SweepKey       扫地热键（I=23, K=37, B=48；菜单里也能直接改键）
  SweepStopEvent 再按一次时用来打断扫地的事件（默认 IdleStop）
  MeltWarmHours  化水所需的「白天小时数」
  FreezeColdHours 结冰所需的「夜里小时数」
  WaterSoakSeconds 水洼存留几秒后被土地吸收
  PuddleCount / PuddleSpread 每次出水几滩、散多开

----------------------------------------------------------
 数据与日志
----------------------------------------------------------

* 日志：文档\My Games\Skyrim Special Edition\SKSE\Nivalis.log
